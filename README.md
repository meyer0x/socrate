# Socrate has moved

> [!IMPORTANT]
> This repository is archived. Socrate now lives at **[github.com/AVEST-VAP/socrate](https://github.com/AVEST-VAP/socrate)**, with its full history, issues welcome and pull requests open.

Socrate lets reviewers comment right on a pull request preview, and lets coding agents read, fix and resolve that feedback. It was created by [Meyer Attal](https://github.com/meyer0x) at [Avest](https://www.avest.fr), which now maintains it.

The npm package is unchanged: `npm install @meyer0x/socrate`.
